XSS FIX PACK FOR csdept2026 forum.html

VERDICT:
The existing forum.js is not XSS-proof because it renders user-controlled Firebase data using innerHTML.

FILES:
1. forum.js
   - Replace your existing forum.js with this file.
   - It uses DOM nodes and textContent/value properties for user data.
   - It avoids putting author names, questions, and answers into HTML template strings.

2. auth-gate.js
   - Add this file to your project root.
   - In forum.html, remove the inline gatekeeper script:
       <script>
           if (localStorage.getItem("isLoggedIn") !== "true") {
               window.location.replace("login.html");
           }
       </script>
   - Replace it with:
       <script src="auth-gate.js"></script>

3. vercel.json
   - Add this at the project root.
   - It adds a Content-Security-Policy and basic hardening headers.

IMPORTANT:
- Firebase security rules must also be checked. Client-side localStorage login can be bypassed.
- A CSP is a backup defense; the main XSS fix is avoiding innerHTML for user content.
- After deployment, test by posting this as a forum question:
    <img src=x onerror=alert(1)>
  It should display as text, not execute.
